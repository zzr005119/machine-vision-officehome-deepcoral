# CORAL / Visual Lab 前端

静态前端使用 HTML、CSS、原生 JavaScript 与 Canvas，无 npm 依赖或构建步骤。首页的双域粒子是概念艺术演绎；特征空间读取仓库的真实训练图像 PCA 坐标。页面使用仓库中冻结的短窗模型 ID、类别映射和 PCA，不需要下载 Office-Home 数据集或权重。

## 页面内容

1. 艺术化首页、双域粒子动画和四域视觉演绎。
2. 单张与批量图片选择、拖放、预览、删除。只接受 JPG、PNG、WEBP，每张最多 10 MiB，最多 12 张，解码后限制 4,000 万像素。
3. 模型接入后显示 Top-5 与每张图片的错误。批量请求依次发送并保留图像顺序，支持取消和超时。
4. Product / Clipart 各 512 个真实参考点。支持域开关、拖动、缩放、键盘平移与定位上传图像。
5. 正式 ResNet18 实验与 ResNet50 短窗演示分别呈现，数据引用仓库原说明。

## 连接模型

默认 web/config.js 的 apiBase 为空，网页显示“模型服务待接入”，不会生成假预测或上传图像。可以点击页面“模型服务待接入”，输入已有服务地址；此设置仅在当前页面内存中使用，不持久保存。

也可以在仓库 web/config.js 中设置公开的 HTTPS 基础地址：

    window.CORAL_CONFIG = Object.freeze({
      apiBase: "https://your-model-service.example",
      timeoutMs: 30000
    });

不要在前端配置中放置密钥。HTTPS 网页需要 HTTPS 服务；本机调试允许 localhost / 127.0.0.1。服务状态“地址已设置”仅表示已配置，不意味着已通过连通性检查。

尚未提供 Python HTTP 服务或模型部署。本次只交付前端与接口契约。真正运行需要已有说明中的 best.pt，页面不会下载它或在浏览器中载入 PyTorch。

## HTTP 接口契约

POST <apiBase>/predict

使用 multipart/form-data，图片字段名为 image。浏览器自动设置 boundary，不手工设置 Content-Type。服务应配置允许前端网页来源的 CORS 响应，且不依赖浏览器 Cookie。

返回 application/json：

    {
      "model_id": "pr_cl_deepda_short_window_seed42",
      "checkpoint_sha256": "5298447d38220ddf8456c6115a61c6e55e4dfd68040b6cf720fdc91e2620ee57",
      "top_k": [
        { "class_id": 37, "class_name": "Mug", "probability": 0.50 },
        { "class_id": 5, "class_name": "Bottle", "probability": 0.15 },
        { "class_id": 28, "class_name": "Kettle", "probability": 0.10 },
        { "class_id": 40, "class_name": "Pan", "probability": 0.08 },
        { "class_id": 6, "class_name": "Bucket", "probability": 0.05 }
      ],
      "pca": [1.0, -1.0]
    }

以上数值仅用于说明响应结构，不是模型实测结果，前端没有内置该响应。

top_k 接受 1–5 个不重复的有效类别，通常后端使用 top_k=5。class_id 和 class_name 必须与 data/splits/class_to_idx.json 一致，概率必须有限、在 0–1 内，且 Top-5 概率和不超过 1。结果按概率降序显示。

pca 可以省略；提供时必须是该固定 PCA 下的两个有限数值。model_id 与 checkpoint_sha256 为推荐字段；若提供，前端会校验是否匹配。后端应使用 demo_short_window.py 中 load_model、load_pca 和 predict_image，启动时加载一次，避免每个请求重复加载。

响应示意：

    model = load_model("best.pt", device="cpu")
    pca = load_pca("demo_assets/short_window_pca.json")
    result = predict_image(model, image, top_k=5, pca=pca)

禁止重新拟合上传图片的 PCA，也不能接入旧 ResNet18 / 512 维 PCA。softmax 分数未经置信度校准。

## 验证范围

已用真实 Chromium 内核检查 320、390、768、1024、1440 像素布局、无横向溢出，以及上传类型/大小/损坏检查、12 张批量上限、结果顺序、移除/切换、PCA 操作与参考数据失败重试。

识别链路使用仅供验证的内存模拟服务测试 multipart 请求、Top-5/PCA 渲染、无效响应、HTTP 错误、超时和取消。模拟服务不包含在交付中。尚未拿到真实 best.pt，因此没有声称完成真实模型的端到端验证。

页面没有分析跟踪脚本、外部字体、CDN 图表库或第三方图片。仅在用户开始识别后，所选图片才会发送给已设置的模型服务。
