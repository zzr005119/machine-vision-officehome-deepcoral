# Product → Clipart 短窗版前端接入

Product → Clipart 演示使用 **DeepDA CORAL + 8 批短窗原型，固定种子 42**，模型 ID 为 `pr_cl_deepda_short_window_seed42`。本次交付推理入口与投影，页面由前端成员接入。其余方向与原正式实验记录不变。

## 运行材料

- [推理入口](../demo_short_window.py)、[65 类映射](../data/splits/class_to_idx.json)和[短窗 PCA](../demo_assets/short_window_pca.json)都在仓库内。
- 权重不进 Git。有实验服务器项目读取权限的组员，从项目相对路径 `outputs/deepda_prcl_prototype_pair_2026-11-19_v1/runs/seed42_prototype/best.pt` 获取；无权限时向训练负责人领取。不需要图集，不需要重训。
- 权重为 96,492,067 字节，SHA-256：`5298447d38220ddf8456c6115a61c6e55e4dfd68040b6cf720fdc91e2620ee57`。程序自动核对，不接受种子 7 或旧 ResNet18 的权重。
- 已在 Python 3.10、PyTorch 2.13.0、torchvision 0.28.0 和 Pillow 12.2.0 环境验证。本机沿用 Anaconda，服务器沿用现有 `.venv`。推理不联网下载 ImageNet 权重。

新建本机环境时可使用以下命令。优先使用 CPU，不需要安装服务器的 CUDA 依赖。

```powershell
conda create -n defect-cnn python=3.10
conda activate defect-cnn
python -m pip install torch==2.13.0 torchvision==0.28.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install Pillow==12.2.0
```

```powershell
python demo_short_window.py --checkpoint best.pt --image example.jpg --pca demo_assets/short_window_pca.json
```

`example.jpg` 可以是任意一张本地图片。输出 JSON 中，`top_k` 含 `class_id`、`class_name`、`probability`，`pca` 为二维坐标。此入口不会启动网页。

## 后端接入

```python
from PIL import Image
from demo_short_window import load_model, load_pca, predict_image

model = load_model('best.pt', device='cpu')
pca = load_pca('demo_assets/short_window_pca.json')

def predict(upload):
    with Image.open(upload) as image:
        return predict_image(model, image, top_k=5, pca=pca)
```

服务启动时加载一次模型与 PCA，单图和批量请求共享同一实例；批量响应保留图像顺序与逐图错误。短窗只用于训练，推理不维护窗口。该模型是 ResNet50 + 256 维瓶颈，预处理采用 RGB 直接缩放至 224×224 和 ImageNet 归一化，不能套用旧 ResNet18 的中心裁剪或 512 维 PCA。

散点图从 JSON 的 `reference_points.Product` 和 `reference_points.Clipart` 各读取 512 个参考坐标，新图的 `pca` 点叠加到同一坐标系，不重新拟合。概率是 softmax 输出，未做置信度校准。

## 验收

服务器真实权重严格重载，8 张训练图的预处理、65 维 logits、256 维特征均与冻结的 DeepDA 推理逐值一致。[PCA 生成入口](../build_short_window_pca.py)仅用于组内复现，需要组内固定的 `train.csv` 与 Office-Home 训练图。前端直接使用仓库中的预计算 PCA，不需要生成。CPU 四线程预热后 32 次单图测量，预处理、Top-5 与投影合计 P95 为 59.42 ms，不计首次加载、解码、传输和页面渲染。

组员接入后仍需验收上传、示例、批量、投影及整页耗时。短窗版在既有 Clipart 测试集为 310/630（49.21%）；配对收益见[量化错分报告](三方向量化错分分析_2026-11-19.md)，不替换课程主结果。

模型来源：jindongwang/transferlearning 的 DeepDA，冻结提交 `7f22c8a9c598e3919838e7f2e8a952bf9beda970`。推理入口使用 torchvision 重建兼容计算图，不加载上游训练程序。
