# Office-Home 数据解压与分层抽检

检查日期：2026-11-03。本报告区分实际检查、发现的问题和未检查内容，不将抽检结论推广为全量图片质量保证。

## 1. 数据与解压

- 压缩包：`data/downloads/OfficeHomeDataset_10072016.zip`，1,132,166,928字节。
- SHA-256：`4B3EE939C181E508109064C484D59BCFF0386BDF15960E8D11305EE5C4BB81FF`。
- 解压目录：`data/raw/OfficeHomeDataset_10072016/`。解压前检查所有条目解析后的路径均位于该目录范围内。
- 实际解压15,590个文件，共1,187,445,785字节，与中央目录的文件数量、逐文件大小和总大小一致。
- 其中15,588张JPG，另有 `ImageInfo.csv`、`imagelist.txt` 两个原始元数据文件。原始元数据中的历史绝对路径不直接作为本机加载路径。

## 2. 抽样方案

按组内确认，方案记录在项目说明中，后续由组内向老师说明；报告不将该安排记为老师已确认。

抽样种子42，按排序后的域名、类别名遍历，每组将JPG路径排序后，用同一个 `random.Random(42)` 随机生成器连续抽最多10张。共覆盖260组、抽2,600张，占全体约16.68%。这是按组分层抽样，不是每张图片等概率的全体简单随机抽样。

每张样本执行：

1. Pillow `verify()` 文件检查。
2. 重新打开并 `load()` 完整解码。
3. RGB转换检查，记录原模式、尺寸、警告和异常。
4. SHA-256摘要，用于识别样本内字节相同的文件。

结果：2,600张全部通过，无解码异常、无警告，全部原模式为RGB。样本宽度42至5,616像素，高度9至4,984像素。9像素高的 `Clipart/Ruler/00055.jpg` 和另一张11像素高的尺子图片已查看，属于细长尺子插画，不按小尺寸直接认定损坏或删除。

另查看了覆盖四域、8类的32张代表图片拼图，以及3组样本内标签冲突和2张极窄图片。此可视查看用于确认域结构和异常，不是2,600张图片全部人工判读。

清单见 [sample_manifest_seed42.csv](./sample_manifest_seed42.csv)，数量见 [class_counts.csv](./class_counts.csv)，机器记录见 [sample_check_2026-11-03.json](./sample_check_2026-11-03.json)。

## 3. 重复与标签冲突

样本内先发现9组字节相同图片，其中3组跨类别。随后使用所有JPG中央目录的“CRC32＋未压缩大小”分组，只读取重复候选文件并比较SHA-256；未对全量图片进行解码。

| 检查项 | 结果 |
| --- | ---: |
| 重复候选文件 | 810 |
| 实际读取候选字节数 | 38,700,979 |
| 确认字节相同的分组 | 398 |
| 相对每组保留1份的冗余文件数 | 412 |
| 跨域的相同图片分组 | 9，涉及21个文件 |
| 跨类别的相同图片分组 | 87，涉及178个文件 |

样本内已查看的冲突例子：

- `Art/Keyboard/00010.jpg` 与 `Art/Laptop/00023.jpg` 是同一张键盘图片。
- `Clipart/Bottle/00088.jpg` 与 `Clipart/Soda/00015.jpg` 是同一张瓶子插画。
- `Clipart/Folder/00010.jpg` 与 `Clipart/Notebook/00001.jpg` 是同一张带活页夹的插画。

有些相邻语义类别本身存在歧义；目前不改原标签、不删除原文件，也不推断87组已全部人工核对。全部分组和路径见 [duplicate_check_2026-11-03.json](./duplicate_check_2026-11-03.json)。

## 4. 数据协议与后续处理

用户已确认采用按域与类别尽可能分层的70%／15%／15%训练、验证、测试划分，种子42。同一内容的重复组不得跨集合；跨域重复也必须一起约束，避免源域训练图片同时出现在目标域测试中。

四域统一类别映射已生成到 `data/splits/class_to_idx.json`，划分CSV尚未生成。冻结清单前需统一记录跨类别重复的处理方式；后续训练应从清单引用原图。

当前抽检没有做训练、选参或按预测结果挑图，因此不因抽检而自动排除这些图片。今后训练链路调试使用的样本应另行记录，避免用于最终测试。

未抽中的12,988张图片未逐张解码；近重复、重新编码的同内容图片和全部图片语义标注未检查。目录与字节检查、抽检通过都不等于这些内容全部通过。
