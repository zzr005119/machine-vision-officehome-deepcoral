## 数据准备

本地已有 `data/downloads/OfficeHomeDataset_10072016.zip`，已解压到 `data/raw/OfficeHomeDataset_10072016/`。原始图片、数据压缩包、模型权重和训练输出不提交 Git。

服务器项目下采用相同数据布局；压缩包SHA-256与本地一致，解压数量、文件大小及类别映射已核对，详见[服务器数据验收记录](./data/reports/server_dataset_2026-11-03.json)。

2026-11-03 已确认四个域具有相同65类，共15,588张 JPG；实际解压文件总计1,187,445,785字节。抽检2,600张图片均通过解码及RGB转换。重复候选筛查确认398组字节相同图片，其中87组跨类别，详见抽检报告。

重新准备数据时可在项目根目录的 PowerShell 中执行以下命令；已有解压目录时先检查目录内容，避免覆盖：

```powershell
New-Item -ItemType Directory -Path '.\data\raw' -Force | Out-Null
Expand-Archive -LiteralPath '.\data\downloads\OfficeHomeDataset_10072016.zip' -DestinationPath '.\data\raw'
```

克隆仓库后需自行准备数据，压缩包不随 Git 下载；来源线索见实验流程与下载说明。

## 抽样方案与数据协议

按组内当前安排，抽样方案记录在项目说明中，后续由组内向老师说明；本地准备继续推进，不把老师已确认作为事实。

- 检查方案：固定种子42，按“域＋类别”分层，每组随机抽最多10张，覆盖4域×65类，共抽检2,600张，占全部图片约16.68%。
- 抽检内容：完整解码、RGB转换、尺寸和模式记录；全量只检查文件目录与大小，重复候选另做字节校验，不逐张解码全部图片。
- 正式数据：使用四域65类，在重复分组处理后，按“域＋类别”尽可能分层划分70%训练、15%验证、15%测试，种子42；同一内容的重复组不得跨集合。
- 状态：划分比例和种子已经组内确认；类别映射已生成，训练／验证／测试清单尚未生成。跨类别重复的处理需在冻结清单前统一记录。
- 抽检没有用于训练或调参，因此不会仅因图片被抽检就将其排除。无监督适配不使用目标域标签，目标域测试集仅用于最终评价。

## 训练环境

正式训练使用L20服务器，项目位于 `/data/zzr/machine-vision-officehome-deepcoral`，独立虚拟环境为其 `.venv`。Python 3.10.12、CUDA版PyTorch及依赖已安装，`pip check` 和一次实际GPU合成训练更新均通过。启用方式：

```bash
cd /data/zzr/machine-vision-officehome-deepcoral
source .venv/bin/activate
```

依赖锁定和检查边界见[服务器环境](./docs/服务器环境.md)。完整训练和真实数据测速尚未进行。

本机 RTX 4060 Laptop GPU 约8 GiB显存。已用现有环境完成 ResNet18、224×224、源域16张＋目标域16张、AdamW及CORAL损失的短程合成训练探测：FP32峰值已分配显存899.6 MiB，AMP为573.0 MiB。本机用于开发和前端调试。

两台设备的探测均未使用真实数据加载和预训练权重，不能据此承诺完整训练耗时或比较训练速度。
