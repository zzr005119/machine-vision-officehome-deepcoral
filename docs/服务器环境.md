## 依赖复现

当前环境已经创建并安装依赖。仅在新检出目录中重新准备时执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --index-url https://download.pytorch.org/whl/cu126 --extra-index-url https://pypi.org/simple -r requirements-server.lock.txt
python -m pip check
```

直接依赖见 [requirements-server.txt](../requirements-server.txt)，实际安装的运行依赖版本见 [requirements-server.lock.txt](../requirements-server.lock.txt)。锁定文件记录本次 Linux / Python 3.10 环境，不保证跨系统直接复用；正式实现若新增依赖，应同步更新环境和锁定文件。
