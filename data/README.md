## 2026-11-03 检查结果

- 四个域的65个类别目录完全一致，统一映射见 [class_to_idx.json](./splits/class_to_idx.json)。
- 固定种子42，每个“域＋类别”抽10张，共2,600张，约16.68%；全部通过Pillow校验、完整解码及RGB转换，未出现解码警告。
- 抽样图片宽度42至5,616像素，高度9至4,984像素。查看发现最窄样本为尺子插画，能正常显示，因此不按尺寸直接删除。
- 用全部JPG条目的CRC32与大小筛选重复候选，只读取810个候选文件，约38.7 MB，进行SHA-256比对；确认398组字节相同图片，冗余副本412个。其中9组跨域，87组跨类别。
- 跨类别重复涉及178个文件；保留原图和原标签，冻结划分前统一记录处理方式。同内容重复组须处于同一集合，避免信息泄漏。
- 未全量逐图解码，未检查近重复及重新编码的相同图片。抽检通过不等于全量无损坏。
